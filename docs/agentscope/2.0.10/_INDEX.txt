# AgentScope: Chinese AgentScope 2.0.10

> ## Agent Instructions
> For AgentScope Python, use https://docs.agentscope.io/stable/en/index for new projects. For existing projects, check the installed agentscope version and use matching versioned documentation.
> The /latest/ alias points to the newest documentation and may move ahead of /stable/ when a development version exists. Do not mix AgentScope 1.x and 2.x APIs.
> State the AgentScope version when providing installation commands or code examples. ReMe uses its own continuously updated /reme/latest/ documentation.

### 核心模块

- [消息与事件](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/message-and-event.md): 智能体通信，与前端流式数据传输
- [计划模式](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/plan.md): 为智能体提供结构化任务清单，用于规划、追踪并协调复杂工作
- [标准作业流程](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/sop.md): 把多步任务拆成逐个验收的里程碑，让智能体按固定顺序推进
- [中间件](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/middleware.md): 在智能体生命周期的关键位置拦截并扩展行为
- [RAG](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/rag.md): 为智能体构建检索增强生成（RAG）能力。
- [长期记忆](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/long-term-memory.md): 基于智能体中间件实现的，跨会话长期记忆
- [终端 UI](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/console.md): 在终端快速测试、验证智能体运行逻辑
- [A2A 协议](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/a2a.md): 连接并与 A2A 协议后的智能体进行对话

#### 流水线

- [概述](https://docs.agentscope.io/zh/versions/2.0.10/building-blocks/pipeline/overview.md): 按照固化逻辑运行多智能体，并向外提供统一接口
