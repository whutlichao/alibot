# 人类面只可配置回应预算上界

原有人类面纪律禁止写入回应预算，以保留后端对 `used` 用量事实的唯一控制；用户于 2026-10-16 人定，允许在频道设置新增 `PATCH /api/channels/{id}/budget`，但只可写上界、不可写用量，配置存于库内逐频道项并缺省回落到内置默认值，变更从下一个人类世代生效。后端仍只在开世代动作落库时重置 `used`，并在一次 Agent→Agent 跳实际投递时推进一次；此边界变化是把“人类面不能写预算”收窄为“人类面只能写上界”，不削弱跳数正本与零投递耗尽语义。默认值仍为 3，本 ADR 不修订或取代 ADR-0002；其具体数值是否合适由实测票另行裁定。
