圆角与阴影 · 小半径、发丝投影

圆角只有四档：6 / 8 / 12 / 16，外加全圆药丸形（仅用于计数、标签、状态、反应 chip）。阴影克制且带方向感，只出现在浮层、弹窗与抽屉 —— 静止内容不加投影，纵深靠表面层级和发丝描边。

头像瓦片使用 7px 圆角（介于 sm 与 md 之间），是刻意的方形观感；不要改成圆形。

阴影层级

only layered surfaces
--shadow-composer
0 1px 2px · 静止输入区极轻的贴地感
--shadow-card
0 2px 8px -4px · 卡片 hover 抬升
--shadow-pop
0 10px 30px -12px + 0 2px 6px -2px · 浮层 / 弹窗 / 抽屉

阴影的用途是「这块浮起来了」，不是装饰。静止的卡片、面板、行不使用阴影。
