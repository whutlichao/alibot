排印规则

mono = structure
  • 标题用负字距 -0.01 / -0.02em；全大写等宽小标签用正字距 +0.08 / +0.1em。
  • 所有数字加 font-variant-numeric: tabular-nums，保证计数、指标、时间戳对齐。
  • 标识符、时间戳、计数、指标、键值行、小节标签一律等宽 —— 等宽即结构。
  • 通用正文行高 1.5；频道/线程消息正文 14px，行高分别为 1.65 / 1.7；fenced React CodeBlock 为 12px / 1.62。
  • 不使用展示型衬线体，不引入无法渲染中文的 webfont。
