worksplice design system · color 01

基础色板 · 表面、文字与强调色

产品的六个承重令牌 —— --bg / --surface / --fg / --muted / --border / --accent —— 以及它们的层级色。所有取值直接来自源文件 worksplice-app.html 的 :root，全部使用 oklch()，不得引入 hex。方向是马卡龙暖奶霜 + pastel 角色族（ADR-0015）：每个色相族提供填充档 / 淡底档 / 文字档 / 图形档。

索引 基础色 语义色 头像色 字体 间距 圆角阴影 按钮 状态 卡片 消息 品牌资产 应用界面

表面层级

bg → panel → surface
--bgoklch(98% 0.011 85)
--paneloklch(95.7% 0.018 85)
--panel-2oklch(93.1% 0.022 84)
--surfaceoklch(99.4% 0.006 85)

层级顺序用于制造纵深：页面底 → 侧栏/看板列 → 嵌套信息井 → 卡片/弹层。静止内容不加投影。

文字层级

fg / muted / faint
频道标题 · --fg oklch(33% 0.045 300)
次级正文与未激活标签 · --muted oklch(46% 0.030 300)
三级提示、占位符、时间戳 · --faint oklch(52% 0.024 300)
--fgoklch(33% 0.045 300)主文字（深梅墨） / 激活态
--mutedoklch(46% 0.030 300)次级文字
--faintoklch(52% 0.024 300)三级 / 元信息

行动族 · 樱粉

accent · hue 356.8 · 四档
--accentoklch(85.7% 0.086 356.8) · fill
--accent-hoveroklch(79.4% 0.104 356.6) · fill
--accent-softmix 22%
--accent-graphicoklch(62.6% 0.086 356.7) · 环·点

行动 = 樱粉：主按钮 / composer send / agent 身份。填充档只做填充（深墨 --on-accent 压其上 7.75:1）；文字与焦点环分别走 --accent-deep（4.51:1）与 --accent-graphic（3.02:1）。旧方向的「淡线档」已退役，边界一律取图形档（ADR-0015）。

描边与分隔

hairline only
--border · oklch(90% 0.013 86) —— 分隔线、静止卡片
--border-strong · oklch(78% 0.020 86) —— 输入框、可交互边框
虚线用于 .kv 键值行与字体样张的细分隔

令牌契约

don't rename

现有 Next.js 组件（AppShell、ChannelView、DetailPanel）按名字依赖这六个令牌。改色值可以，改名字会一次性击穿整个应用。

--bg页面画布
--surface卡片 / 面板 / 顶栏
--fg主文字 / 激活下划线
--muted次级文字 / 未激活
--border发丝分隔
--accent行动 / Agent（fill 档）
