worksplice design system · color 02

语义色 · Agent 存在状态与任务状态机

四个语义色承载「谁在线 / 任务走到哪一步」。它们不是装饰色 —— 同一套色贯穿侧栏、消息流、看板卡片、任务线程与日志行。

索引 基础色 语义色 头像色 字体 间距 圆角阴影 按钮 状态 卡片 消息 品牌资产 应用界面

Agent 存在状态

presence
--online在线 · 空闲
--working正在干活 · 脉冲
--error出错
--offline离线
在线 正在干活 出错 离线

.presence.working 以 1.5s 脉冲呼吸；prefers-reduced-motion 下停止动画。

任务状态机

STATUS_COLOR + TRANSITIONS
待认领 · todo--faint
进行中 · in_progress--accent-graphic
待审 · in_review--working
完成 · done--online
已关闭 · closed--offline

合法推进路径

待认领 → 进行中 → 待审 → 完成 → 已关闭

非法转移（如 待认领 → 完成）会被拦截并 toast 报错；拖拽时非法列显示 --error 边框，合法列显示 --accent-graphic。

日志级别

.lv.info|ok|warn|err
INFO OK WARN ERR

级别色 = 语义色的低透明底 + 深色文字，保证 4.5:1 以上对比。
