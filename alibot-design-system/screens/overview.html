看这些切片时的三条约定

  • 组件只有一份实现。所有类来自 ui_kits/app/app.css；切片文件里只有 「切片机架」样式（返回索引的角标、把 position:fixed 的浮层收进对照舞台）。 改动视觉请改 app.css，不要改切片。
  • 状态类以静态方式呈现。原型里的交互脚本已按本包惯例裁剪，因此 .is-active / .is-on / .drag-over / .invalid-over / .dragging / .badge 这类状态被显式摆出；而纯 hover 态 （.msg-tools、.nav-row:hover）无法在静止页驻留， 各切片用一行注解说明取值，不伪造常驻效果。
  • 产品角色族来自包内的产品扩展层。切片按 SKILL.md §1 依次加载两个 foundation 与产品扩展层 ui_kits/app/product-ext.css （--selected* / --unread* / --warn*）—— 它与 app 层的 app/alibot/studio/product-tokens.css 是同值同源的两份落点， 本包只引用包内那份，因此包被复制到别处也不会掉色。
